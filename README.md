# 메트로게이션 (Metrogation) — 교통약자 지하철역 3D 이동도움 앱

[lee2740/Metrogation](https://github.com/lee2740/Metrogation)의 3D 지하철역 안내도 아이디어를 바탕으로, **교통약자(휠체어·유모차, 시각장애인, 고령자·보행약자)**의 역내 이동을 돕기 위해 확장 제작한 3D 웹 애플리케이션입니다.

## 주요 기능

1. **교통약자 유형별 맞춤 경로 탐색 (`js/routing.js`)**
   - **♿ 휠체어 · 유모차**: 계단 및 에스컬레이터 완전 제외, 엘리베이터·교통약자용 넓은 개찰구만 이용
   - **🦯 시각장애인**: 점자블록(`tactile`) 동선 우선 탐색 및 3D 점자블록 하이라이트
   - **🦯 고령자 · 보행약자**: 계단 회피 및 엘리베이터 우선 안내
   - **🚶 일반 최단 경로**: 최단 거리 기준 안내
2. **교통약자 편의시설 3D 안내 및 바로가기**
   - 장애인 화장실, 전동휠체어 급속충전기, 수유실, 음성·점자 안내도, 역무실 위치 3D 마커 표시 및 원클릭 목적지 설정
   - 역무원 도움 요청 모달 및 역무실 길찾기 연계
3. **1인칭 시점 3D 이동 시뮬레이션 & 단계별 카메라 포커스 (`js/engine3d.js`)**
   - 이동 유형별 눈높이(휠체어 1.15m / 보행 1.55~1.62m)로 경로를 미리 주행하는 1인칭 시뮬레이션
   - 상단 HUD 실시간 층/단계 안내 및 진행률 슬라이더
   - 경로 목록 각 단계 클릭 시 해당 3D 지점으로 카메라 자동 이동
4. **접근성 UI & 데이터 확장 구조 (`js/stations.js`)**
   - 큰 글씨 모드, 고대비 모드, 한국어 음성 안내(Web Speech API) 지원
   - `window.STATION_DATA` 객체에 새로운 역 데이터를 추가하면 즉시 선택 및 3D 렌더링 가능 (경성대·부경대역 + 서면역 환승 샘플 포함)

## 실행 방법

별도의 빌드 과정 없이 `index.html`을 브라우저로 열거나 로컬 정적 서버로 실행하면 됩니다.
(Three.js r128 및 Noto Sans KR 폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)
